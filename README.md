# Back-End-Development-Pictures

Pictures REST microservice for the Back-End Development Capstone.

Based on the IBM Skills Network Pictures service template.

## API

- GET /health
- GET /count
- GET /picture
- GET /picture/<id>
- POST /picture
- PUT /picture/<id>
- DELETE /picture/<id>

## Development

Install dependencies in an isolated Python environment, then run `python -m pytest -v`.
